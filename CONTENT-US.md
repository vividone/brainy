# Content tracker — American (Common Core)

Where the US pack actually stands, and how it got there.

- **Coverage below is generated.** Run `npm run content:track` after adding
  skills; everything between the coverage markers is rewritten from the pack
  itself, so the numbers cannot drift. Everything outside them is written by
  hand and is preserved.
- **Source of truth for what to build:** **Common Core State Standards for Mathematics** (CCSSI), which set out
  content by grade with stable identifiers such as `3.NBT.A.1`. Those
  identifiers are worth carrying in the skill definitions, because they make a
  coverage gap checkable against the standard rather than against an opinion.
- **Two checks, not one.** `npm run smoke` proves every generator makes
  well-formed, answerable items. It cannot see that two options are the same
  number, or that an explanation contradicts its own answer. `npm run sample
  <skill-id>` prints real questions with their options and answers, and that is
  what catches those. New skills go through both.

## Status

**Math is now complete across Kindergarten–Grade 5.** Every grade has content,
so no parent can pick one that hands their child a blank screen.

Still math only: Quantitative Reasoning, Verbal Reasoning and the rest are
declared and locked. Every skill carries its Common Core code in `concepts`
(`3.NF.A.3`, `5.MD.C.5`), which makes a coverage gap checkable against the
standard rather than against an opinion — worth backfilling into the other two
packs.

Grade 3 is the deepest at twelve skills; the rest are three to five.
